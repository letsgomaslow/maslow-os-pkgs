# Experimental native Free cloud AI package

Current status, October 15, 2026: backend **0.1.0-3** is installed with Voice44 and Hub2.0.3. The original recovery prerequisite was settled through its owning path; saved-state preservation and canonical Hub rollback/reapply pass. See [the packaging baseline](../../docs/hub-2-baseline.md) and runtime handoff for exact inputs and limits. Older backend1/2 and unsigned-candidate notes are historical; they do not authorize rerunning recovery, publishing, promoting gates or claiming wider Free AI acceptance.

Build with an explicit `MASLOW_FREE_AI_SRC` pointing to the reviewed extracted runtime checkout and `MASLOW_RUNTIME_ARCHIVE` pointing to its exact git archive. `source-integrity.json` must contain the exact source hashes and be marked reviewed by the coordinator only after owning source checks and review. It intentionally fails closed while pending. There is no fallback to a stale public runtime HEAD. FreeLLMAPI and the private Node binary are fetched from exact checksum-verified upstream archives.

The source build uses Node 22.23.3 and the unchanged upstream server/shared dependency lock. Runtime uses the separate checksum-pinned `production-lock.json` with five exact roots: Express, zod, Ajv, multer and better-sqlite3. The approved production-only safety pins are proxy-addr 2.0.8, qs 6.16.0, fast-uri 3.1.8 and multer 2.4.0, with qs's required side-channel 1.1.1. All other retained dependency versions and artifact integrities match the original source lock. Unused compression, undici, SOCKS and Sharp/libvips trees are omitted; missing-Sharp normalization and actual compiled text/function HTTP are checked separately. Media input remains rejected by the fixed router policy.

Only `maslow-main`'s local import closure is bundled into one private entry. Both hoisted and workspace-nested production dependencies are retained and audited. The package has no system Node/npm replacement, upstream server index, client, CLI, Electron, desktop update tools, development dependencies or package bin launchers. Runtime ownership is limited to `/usr/lib/maslow-free-ai`, `/usr/bin/omarchy-free-ai`, package compatibility metadata and license notices. This preview builder's SQLite requires glibc 2.44 and GLIBCXX 3.4.30; older runtime acceptance needs a compatible rebuild, never a silent system upgrade.

The compatibility metadata records upstream, lock, exact adapter inputs, compiled inputs, entry hash and production dependencies. Task support requires a separately reviewed Voice containing `task_submit`, typed tasks independent of audio and the `free-cloud` execution connection. The coordinated Voice recipe packages these source modules; package presence does not establish installed task readiness. Provider credentials are never build inputs. Source/ABI/bootstrap checks use synthetic credentials and disable outbound fetch for bootstrap.
